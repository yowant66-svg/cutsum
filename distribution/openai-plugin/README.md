# CutSum OpenAI Plugin

This distribution packages the repository's `cutsum-intelligence` Skill without copying or
forking its instructions. Install the generated ZIP through a compatible Codex plugin workflow.

The plugin is an independently maintained CutSum distribution. It is not a claim of inclusion in
an official OpenAI marketplace. Runtime capability boundaries remain authoritative: it does not
add downloading, publishing, cloud providers, OCR, audio classification, or visual tracking.
