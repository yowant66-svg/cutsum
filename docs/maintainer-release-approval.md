Maintainer: DXBATM

Release: CutSum `0.1.0a4`

The maintainer authorized Codex to complete and publish this GitHub Alpha Release under the
following boundaries:

- Use the project and distribution names `CutSum` and `cutsum` for this Alpha, accepting that the
  repository's engineering name checks are not a legal trademark opinion.
- Publish the wording in `provenance/ledger.yaml` as an engineering provenance record. Statements
  such as `REFERENCE_REWRITE`, `NEW_ORIGINAL`, and `no copied block` are engineering conclusions,
  not judicial findings or guarantees of non-infringement.
- Keep benchmark materials limited to URLs, metadata, bounded curator summaries/paraphrases,
  synthetic fixtures, and rights notes already present in the repository. Do not publish downloaded
  media, complete third-party transcripts, credentials, cookies, or private account data.
- Publish rights-safe examples made from FFmpeg-generated test media and maintainer-authored
  synthetic transcripts.
- Publish the same wheel and source distribution through TestPyPI, PyPI, and GitHub Release using
  GitHub OIDC Trusted Publishing; also publish the SBOM, checksums, release manifest, and
  reproducible OpenAI Plugin ZIP. Do not create or store a long-lived PyPI API token.
- Continue describing sports support as transcript-only heuristic Alpha and avoid claims of visual,
  audio, OCR, scoreboard, MatchState, precision/recall, or proven editorial quality.

The maintainer did not separately attest in this approval that every generated clip was personally
viewed. Automated tests and synthetic playback evidence establish engineering behavior only, so the
release must not convert them into an editorial-quality claim.
