# CutSum 0.1.0a1 — Public Alpha

CutSum is a provider-neutral engine for turning local long-form media and transcripts into portable
clip plans and verified media outputs. This first Alpha is intended for developers, creators,
course and podcast teams, automation workflows, and AI agents that want an offline deterministic
core without coupling the workflow to one model or platform.

## Included

- Python SDK, `cutsum` CLI, compatible `cutup` alias, and repository-local Agent Skill.
- Local video/audio plus SRT, VTT, and JSON transcript inputs.
- Portable CutPlan, explicit runtime media binding, provenance records, file hashes, and
  no-overwrite FFmpeg execution.
- Education distillation, replaceable Highlight14 assessment, semantic subtitle sidecars and
  capability-gated burn-in.
- Deterministic 9:16 composition modes and platform safe areas.
- Transcript-only heuristic Sports Highlight Alpha for six sports profiles.
- Three rights-safe reproducible examples built from synthetic media and transcripts.

## Install

Download the wheel and verify it with `SHA256SUMS.txt`, then run:

```bash
python -m pip install cutsum-0.1.0a1-py3-none-any.whl
cutsum capabilities
```

Python 3.11–3.13 and an FFmpeg/ffprobe installation are required for media execution.

## Important limits

This release does not bundle YouTube downloading, ASR, translation models, cloud Providers, model
weights, face or speaker tracking, sports visual/audio/OCR confirmation, MatchState, or platform
publishing. Sports detection is transcript-only and heuristic. Automated benchmarks and generated
examples establish engineering behavior, not universal editorial quality.

CutSum is not published on PyPI in this release. Use only the assets attached to this GitHub
Release and report suspected vulnerabilities through GitHub private vulnerability reporting or
`yowant66@gmail.com`.
