# CutSum 0.1.0a2 — Public Alpha

CutSum `0.1.0a2` is the second public Alpha of the provider-neutral long-video planning and media
execution engine. It hardens real-media boundaries discovered after the first Alpha while retaining
the portable CutPlan, Python SDK, CLI, repository-local Skill, and deterministic offline core.

## What changed

- Improved educational segment completeness and preserved independent clip boundaries.
- Enforced requested clip counts, duration limits, vertical canvas constraints, subtitle reading
  speed, cue duration, overlay bounds, and bilingual display order.
- Hardened media inspection for rotation, corrupt inputs, duration mismatch, Unicode paths, HEVC,
  AV1, variable frame rate, and audio-only execution boundaries.
- Fixed sports count parsing and kept public sports profiles within the documented Alpha scope.
- Added fail-closed output-root checks, translation-provenance requirements, and correct subtitle
  sidecar media types.
- Limited generic `full` execution to 24 clips by default unless the caller explicitly opts in to a
  higher maximum.

## Install

Download the wheel and verify it with `SHA256SUMS.txt`, then run:

```bash
python -m pip install cutsum-0.1.0a2-py3-none-any.whl
cutsum capabilities
```

Python 3.11–3.13 and FFmpeg/ffprobe are required for media execution.

## Important limits

Sports support remains transcript-only heuristic Alpha. This release does not claim visual,
audio, OCR, scoreboard, or MatchState confirmation. CutSum does not bundle YouTube downloading,
ASR, translation models, cloud Providers, model weights, face or speaker tracking, or platform
publishing. Automated tests and generated examples establish engineering behavior, not universal
editorial quality.

CutSum is not published on PyPI. Use the assets attached to this GitHub Release and report suspected
vulnerabilities through GitHub private vulnerability reporting or `yowant66@gmail.com`.
