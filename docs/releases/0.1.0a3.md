# CutSum 0.1.0a3 — Public Alpha

CutSum `0.1.0a3` is a focused public Alpha reliability release based on independent black-box and
second-pass source review of `0.1.0a2`. It closes empty-result, hard-constraint, cancellation, and
no-overwrite defects without expanding the documented product boundary.

## What changed

- Sports transcript planning now returns a valid empty CutPlan with an explicit warning when no
  qualified event is found.
- Delayed explicit cancellation language can retract the latest related score or finish result
  across the bounded transcript context used by the heuristic provider.
- Compound Chinese and multi-digit clip counts remain whole hard constraints in sports and
  educational DIRECTED requests.
- Mixed required and forbidden markers inside one sports event class fail closed when the current
  protocol cannot safely express the requested subtype distinction.
- `cut` and `full` reject an existing execution record before media rendering begins.
- Plan and JSON outputs consistently use structured `OUTPUT_EXISTS` errors instead of raw
  `FileExistsError` diagnostics.
- CLI fallback errors distinguish missing sources, invalid protocol input, permission failures,
  and unexpected internal failures while keeping local paths private.
- The standalone Schema exporter now resolves the repository source package in clean checkouts.

## Install

Download the wheel and verify it with `SHA256SUMS.txt`, then run:

```bash
python -m pip install cutsum-0.1.0a3-py3-none-any.whl
cutsum capabilities
```

Python 3.11–3.13 and FFmpeg/ffprobe are required for media execution.

## Important limits

Sports support remains transcript-only heuristic Alpha. A longer cancellation lookback is still a
text rule, not visual, audio, OCR, scoreboard, replay, or MatchState verification. CutSum does not
bundle YouTube downloading, ASR, translation models, cloud Providers, model weights, face or
speaker tracking, or platform publishing. Automated tests establish engineering behavior, not
universal editorial quality.

CutSum is not published on PyPI. Use the assets attached to the GitHub Release and report suspected
vulnerabilities through GitHub private vulnerability reporting or `yowant66@gmail.com`.
