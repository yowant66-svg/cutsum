# CutSum 0.1.0a4 — Adoption-first public Alpha

CutSum `0.1.0a4` is the first PyPI Alpha and focuses on making already-tested behavior easy for a
new user to install, run, inspect, and report. It does not expand the frozen sports, education,
subtitle, or vertical-reframe algorithms.

## Install and prove the local path

Python 3.11–3.13 and FFmpeg/ffprobe are required.

```bash
python -m pip install --pre cutsum==0.1.0a4
cutsum capabilities
cutsum demo cutsum-demo
```

The demo creates its own synthetic 60-second source, maintainer-authored transcripts, portable
CutPlans, playable artifacts, ExecutionRecords, and `demo-report.json`. It makes zero network
Provider calls and includes no third-party media.

## Reliability changes

- Subprocess stdout and stderr are drained continuously and retained in bounded head/tail buffers.
- Diagnostic records expose original byte counts, truncation state, and POSIX termination signals.
- The repo-local CutSum Skill can be built into a reproducible OpenAI Plugin ZIP from one source.
- TestPyPI, PyPI, and GitHub Release consume the exact same wheel and sdist artifact build.
- Release upload uses GitHub OIDC Trusted Publishing and stores no long-lived PyPI token.

## Important limits

- Sports support remains transcript-only heuristic Alpha with no audio, video, OCR, scoreboard, or
  MatchState confirmation.
- CutSum does not bundle ASR, translation models, downloaders, publishers, or model weights.
- Fixed-focus vertical composition is not face, speaker, or motion tracking.
- The Plugin ZIP is an independently maintained distribution and does not imply official OpenAI
  marketplace inclusion.
- Automated tests and successful demo execution establish engineering behavior, not universal
  editorial quality.

Verify all GitHub Release assets with `SHA256SUMS.txt` before security-sensitive installation.
