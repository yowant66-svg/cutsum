# Trial invitation template

## English

I am looking for a few real testers for CutSum, an Apache-2.0 open-source engine that turns local
media and transcripts into portable clip plans and verified FFmpeg outputs.

The trial takes about 15–30 minutes. It uses locally generated synthetic media, requires no API key
or account access, and does not upload anything. Please report both successes and failures. Do not
send private media, credentials, cookies, or sensitive transcripts.

Start here: https://github.com/yowant66-svg/cutsum/blob/main/docs/quickstart.md

Repository: https://github.com/yowant66-svg/cutsum

## 简体中文

我正在为 CutSum 寻找少量真实试用者。CutSum 是一个采用 Apache-2.0 许可证的开源项目，
可以把本地媒体和字幕转换成可追溯的剪辑计划，并通过 FFmpeg 生成经过验证的成片。

试用大约需要 15–30 分钟，使用本地生成的合成测试素材，不需要 API Key 或账号权限，
也不会上传文件。成功和失败都请如实反馈。请不要发送私人媒体、凭据、Cookie 或敏感字幕。

开始试用：https://github.com/yowant66-svg/cutsum/blob/main/docs/quickstart.md

项目仓库：https://github.com/yowant66-svg/cutsum
